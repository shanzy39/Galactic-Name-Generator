# Galactic Name Generator

**▶ [Try it live](https://shanzy39.github.io/Galactic-Name-Generator/)**

A tiny, single-file web tool that forges an **original** character name to fit
the species and class story you're about to roll. Made for those moments when
you're staring at the character-creation screen and none of the suggested names
feel right.

Everything runs in your browser. Nothing is uploaded, there is no backend, and
every name is assembled on the fly from invented syllable banks.

## Two ways to name

- **Inspired by my name** - type your real name and it gets phonetically
  reshaped into something that still echoes you, but sounds at home in the
  galaxy (e.g. *Matthew* &rarr; *Matthear Drashkaryr*).
- **Surprise me** - leave the field blank for a fully random pull, or type any
  seed word to get the same set of names back every time.

## Fits species *and* class

Pick from twelve playable-style species, each with its own naming character:

| Species | Flavor |
|---------|--------|
| Human / Cyborg | clean and pronounceable (cyborgs can get a unit designation) |
| Twi'lek | flowing, apostrophe'd |
| Zabrak / Rattataki | hard and guttural |
| Chiss | a single ceremonial multi-part name |
| Sith Pureblood | ancient and sibilant |
| Miraluka / Mirialan | soft and melodic |
| Cathar / Togruta / Nautolan | tribal, rolling, aquatic |

Then choose one of the eight class stories (Republic or Empire). The faction
tone nudges the result harder or smoother to match.

## Sith honorific (optional)

For the two Sith classes you can switch on a dark honorific:

- **Original epithet** (default) - invented titles like *the Hollow* or
  *Voidcaller* appended to the name.
- **Canon-style title** - an opt-in classic dark-side prefix.

## Run it

Just open `index.html` in any browser. To host it, drop the file on GitHub Pages
or any static host - that's the whole app.
